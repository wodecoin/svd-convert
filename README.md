# MCU SVD & SFR/SFD 语义增强转换器

这是一个独立的、基于浏览器的在线工具，旨在帮助嵌入式开发者可视化单片机（MCU）的寄存器定义文件（如 `.svd`, `.sfr`, `.sfd`），并通过内置的语义知识库增强可读性。

## 主要功能

*   **多格式支持**: 支持 CMSIS-SVD (`.svd`, `.xml`) 以及部分工具链（如 Keil）使用的 SFR/SFD (`.sfr`, `.sfd`) 文件。
*   **拖放上传**: 简单地将一个或多个文件拖放到浏览器窗口即可加载。
*   **智能合并**: 能够将来自不同文件（例如一个 SVD 和一个 SFD）的信息进行深度合并，补全缺失的寄存器或位域信息。
*   **语义增强**: 内置了针对 `STM32F1` 系列等常用 MCU 的寄存器和位域的中文语义，例如 `RCC_APB2ENR` 会被自动注解为 "APB2外设时钟使能"。
*   **高效可视化**:
    *   以层级树（外设 -> 寄存器）的形式清晰展示所有硬件寄存器。
    *   自动计算并显示每个寄存器的绝对地址。
    *   提供详细的位域表，包含位范围、名称、语义和原始描述。
*   **快速搜索**: 支持实时对外设和寄存器名称进行不区分大小写的搜索，快速定位目标。
*   **纯前端实现**: 单个 HTML 文件，无需任何后端服务或网络连接，保障了代码和数据的本地化与安全性。

## 如何使用

1.  **打开文件**: 直接在现代浏览器（如 Chrome, Firefox, Edge）中打开 `svd_convert.html` 文件。
2.  **加载文件**: 将你的 `.svd`, `.sfr` 或 `.sfd` 文件拖拽到页面左侧的虚线框内，或点击框体选择文件。
3.  **开始解析**: 点击 **“开始深度解析”** 按钮。工具将处理文件并在右侧生成可交互的寄存器树。
4.  **浏览与搜索**:
    *   点击外设名称可以展开或折叠其下的所有寄存器。
    *   点击寄存器名称可以展开或折叠其详细的位域表。
    *   使用顶部的搜索框输入关键字（如 `GPIOA` 或 `CR1`）来快速筛选。

## 技术简介

*   **前端**: 完全使用原生 JavaScript、HTML5 和 CSS3 构建。
*   **样式**: 借助 [Tailwind CSS](https://tailwindcss.com/) 实现快速、响应式的 UI 设计。
*   **文件解析**:
    *   `.svd`/`.xml` 文件通过浏览器内置的 `DOMParser` 进行解析。
    *   `.sfr`/`.sfd` 文件通过正则表达式进行内容抓取和结构化。

这个工具旨在提供一个比传统文本编辑器或 IDE 插件更轻便、更直观的寄存器查阅体验。
